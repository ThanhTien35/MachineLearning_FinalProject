# Introduction to Machine Learning - Final Project

## 1. Yêu cầu

- Python 3.11 (khuyến nghị).
- Kết nối Internet để cài đặt thư viện và tải dữ liệu.

## 2. Question 1 - Feedforward Neural Network (FNN)

Mở Terminal tại thư mục gốc của project và chạy:

```bash
cd Question1_FNN
python -m pip install -r requirements.txt
python main.py
```

Kết quả được lưu trong thư mục `Question1_FNN/results/`.

## 3. Question 2 - Convolutional Neural Network (CNN)

Mở Terminal tại thư mục gốc của project và chạy:

```bash
cd Question2_CNN
python -m pip install -r requirements.txt
python cnn_cifar10.py
```

Bộ dữ liệu CIFAR-10 sẽ được tải tự động trong lần chạy đầu tiên.

Kết quả được lưu trong thư mục `Question2_CNN/results/`.
